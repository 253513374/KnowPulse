# KnowPulse 微信小程序接入

当前原生工程提供真实 `wx.login` 调用、既有账号绑定、退出、师生工作区、教师测评进度、站内催办、任务/结果自动消息、学生统一站内消息及班级/学生/知识点学情查看、教学方案进度与私有困难跟进、五题型正式作答/图片/交卷核对、学生成绩回顾、材料学习与上交历史、个人教学方案活动、订正文字/图片上交与教师复核、按学校的统一学习安排、同题复练与收藏、本人私有笔记、学生学科成长与逐题依据，以及单个学生评语的草稿、发布、更正、撤回与阅读。按 PRD FR18 的分工，复杂阅卷、评分修订和最终结果发布由 Web 承接；其他教学与学习移动业务仍需继续，不能据此认定 EDU-M3 完成。用户已确认一个 AppID、教师和学生两个独立工作区；实际认证/域名尚未配置，本阶段先完成代码和本地验证。

## 配置与启动

1. 安装微信开发者工具，导入此目录，在 `project.config.json` 填入实际 AppID。`project.private.config.json` 已忽略，不提交个人工具配置。
2. 修改 `config.js`：`apiBaseUrl` 为 API HTTPS 源站（无尾斜杠、路径或查询）；`portalBaseUrl` 为教师 Web HTTPS 源站；`appKey`、`clientId` 与服务器配置一致。当前留空会明确阻止登录，不会回退到演示账号。
3. 在微信后台配置对应 HTTPS request 合法域名、证书及实际环境。不要关闭 `urlCheck` 作为正式验收方法。
4. API Host 与 DbMigrator 使用同一份服务器端配置；运行刚构建的迁移器，既应用绑定表迁移，也登记公有客户端。配置改变后重启 API。不要提交真实密钥。

服务器配置结构如下，**示例中的占位值不能直接启用**：

```json
{
  "WeChatLogin": {
    "Applications": {
      "main": {
        "Enabled": true,
        "DisplayName": "学校教学小程序",
        "AppId": "<实际 wx 开头 AppID>",
        "AppSecret": "<仅服务端注入>",
        "ClientId": "KnowPulse_WeChat_main"
      }
    }
  }
}
```

建议由部署密钥配置注入 `WeChatLogin__Applications__main__AppSecret`，其他字段使用同层级环境变量或不含密钥的环境配置。Host 与迁移器均须获取配置；原生 `config.js` 只含公开源站、别名和客户端 ID。别名限定字母、数字及短横线；启用项不能重复 AppID/ClientId，不能与其他 OIDC 客户端冲突。删除/禁用配置会阻止后续微信登录与业务请求，不删除绑定历史。

## 使用与恢复

在 Web `/account/wechat-bindings` 登录本人已有账号，核对账号与租户，重新输入当前密码并确认绑定本人微信，生成五分钟有效码。小程序粘贴该码，用当前微信绑定；后续从已绑定账号入口登录。小程序不会询问 KnowPulse 密码，也不会通过输入用户 ID、姓名或选择“教师”取得身份。学校任教/在班关系与功能权限仍由服务器确认。

绑定码只展示一次，不进浏览器存储；不要分享。生成响应丢失时，在 Web 重新验证密码生成新码会使旧待绑定码失效。交换响应丢失时可用原码重试，但仍需同一微信的新登录证明。若小程序已丢失绑定标识，在 Web 解除旧绑定后重新绑定，原业务账号和教学记录保留。

访问令牌仅留在运行内存，最长五分钟，无刷新令牌；重新进入或失效后需再次微信登录。工作区刷新前清空旧身份投影，旧请求不得覆盖新账号。退出立即清空本地会话并请求服务端撤销令牌；当前 ABP 的发现文档使用 `/connect/revocat`，客户端复用该地址。网络失败会提示撤销未确认。Web 解除绑定会使该绑定的所有后续请求失效。历史绑定按本人分页查看，解除记录保留；密码/安全戳变化要求重新绑定。

## 检查

在此目录运行 `node --test tests/*.test.cjs`；无 npm 依赖。测试使用平台替身验证会话、读取生命周期、结果投影及真实 Page 脚本，不访问微信。开发者工具编译、真机微信授权/切换、合法域名、真凭据、弱网与各业务页面仍须独立验收。服务端普通 HTTP/OpenIddict 测试中的合成微信证明也不能替代真机验收。多实例正式上线前补充分布式限流与可信代理配置。

## 教师进度与学生结果

在工作区选择学校下的测评入口。教师按本人有效任教范围分页查看已发布任务，进入任务后核对分配、开始、交卷、待确认题目及评分完整度；完整评分不等于已发布，也不推断学生已能看到。未完成总分显示“—”，不把缺考或待批改写成零。可以明确复制该任务的网页地址，正常登录 Web 后继续连续批改、封卷和统一发布；复制的地址只有任务标识，不含令牌或答案。

学生列表不预取答案。打开本人结果后，隐藏状态不显示总分和题目，仅成绩状态只显示正式总分，完整讲评才逐题显示冻结题目、原答、参考依据及教师反馈；通过上一题/下一题切换，避免一次把整卷正文传入视图。缺考保留缺考状态，没有零分答卷。学校字段、任务及接收人配对都重新核对，后台仍独立校验当前身份、关系和开放时间。讲评读取沿用原有接触记录规则，不增加正式答卷或独立掌握证据。

原答图片从带授权的 `GET /api/education/assessment/attempts/{attemptId}/images/{attachmentId}` 读取，不生成公开文件 URL；该入口委托原应用服务检查归属。原生按已提交顺序和旋转显示，支持缩放拖动。页面隐藏、刷新或身份失效时清空正文与图片视图，并尝试删除本次下载的自有临时文件；不将业务正文、成绩或图片路径写入应用存储。临时缓存物理清除仍取决于微信文件系统与设备，D10 和共享设备真机验收尚未完成，不能承诺擦除已看过或复制的内容。

教师进度与学生结果读取页在重新显示时刷新学校身份，拒绝换号、失权或离开后的迟到响应；这些读取页不提交评分、任务封卷、成绩发布或复核命令。当前题目及反馈按原文显示，复杂公式/图表、设备尺寸和原图手势仍待实机核验。

## 教师评语与学生阅读

教师在当前学校的“学生评语中心”选择任教班级和单个学生，核对姓名与账号后新建。日常、测评、阶段评语均先保存云端草稿；测评评语必须明确关联测评，其他类型引用测评事实时也须主动关联。预览使用已保存的确切版本，再次确认接收人和正文才发布；更正、重新发布和撤回须填写原因。私有观察不会自动复制。所有关联测评均开放完整讲评前，学生列表、提醒和正文继续受限；仅成绩开放不能提前开放评语。

草稿、发布和撤回都沿用不可变操作编号。发送前仅持久保存账号/租户/应用范围下的评语、操作和动作标识，不存正文或内部原因。响应待确认时先查原回执，明确重试也先查询，再使用仍在运行内存中的同一请求。查询不到不表示失败，不创建新编号替代。关闭追踪只清除本机标识，不撤销云端事实；关闭进程或卸载页面后无法重发已丢失正文的请求，需要核对云端再编辑。未保存文字只在当前编辑器内存，不能承诺跨页面或冷启动恢复。

页面隐藏或会话到期会隐藏正文；到期后可明确微信重新验证，在同一账号和当前权限下比较内存编辑与云端版本。主动退出、换号、失权或卸载清除正文和精确重试正文。云端版本变化时保留本机文字供比较，禁止直接保存覆盖，须明确重新读取。复制网页地址只适用于已确认保存、没有未保存文字或待确认操作的记录；网页正常登录后打开同一评语，链接不携带正文或凭据。云端草稿才供跨端继续。

学生在当前学校查看评语卡片与版本提醒，列表不预读正文或记已读；明确打开选中版本才记录该版本阅读。旧版本链接不会默默打开新版，更正有独立未读状态。撤回显示通用记录，不再返回旧正文、私有观察或内部原因；已看过、复制的内容不能收回。这是站内版本提醒，不代表微信订阅通知已发送。

操作编号依赖 `wx.getRandomValues`；[微信官方类型定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts) 声明该接口需要基础库 2.15.0。不可用时阻止新写入并提示更新或转网页，不回退到非安全随机数。当前检查覆盖 Page 脚本与真实本地 HTTPS/数据库接口，开发者工具编译、实际微信授权、WXML 渲染、共享设备及弱网验收仍待完成，其余 EDU-M3 功能继续推进。

### 本人私有观察与个人常用语

在固定单个学生的评语编辑器中明确打开两个私有区。观察按当前学校、有效任教、在班与学校成员组合核对，仅作者可读；独立保存不建立或发布学生评语，历史每页 20 条，更正另记一条。观察时间按设备时区输入并转为 UTC，文字保留原文，最多 4000 字符。

明确选择某一条观察、确认复制后，只把这一条文字放入独立评语编辑区。须删去内部判断、确认允许公开的内容并关联引用的测评事实，再保存、预览和确认发布；原观察始终私有。选择其他观察不会自动携带其余记录，保存观察不发学生通知或改变成绩、掌握证据。

个人常用语按本人账号和租户保存，可在本人不同有效任教学校使用，学校或其他教师没有读取权。支持新建、编辑、归档及恢复；每项操作保留修订，默认不列出归档项。选用前重新读取当前非归档版本，确认后替换当前学生评语文字并清除先前观察选择，只改变本机编辑，不自动保存或发送。以后修改、归档常用语不会回写已经复制或发布的学生评语。

常用语同时在 Web 评语页管理。手机、网页冲突时保留本机文字和原云端基准；“供比较”读取不重新设基准，明确确认重新读取才放弃旧编辑。待确认操作与评语共用一个编辑器的标识追踪，彼此不能替代；恢复先查原回执，明确重试才按原号、原正文发送。冷启动可查询原回执，无法重造已经丢失的请求正文。关闭追踪不撤销可能成功的保存，也不等于更新到最新基准。

观察、常用语和精确重试正文只留在当前运行内存，持久存储只含动作及标识。隐藏清空私有视图并阻止迟到响应；会话到期先隐藏，可明确重新核验同一账号继续，退出/换号/失去任教或权限/卸载清空文字和重试正文。复制网页继续入口前，先保存这些私有编辑并核对回执。实际设备留存、完整弱网、学校 D06/D10 与生产并发仍须单独验收。

## 学生正式作答与交卷

学生测评列表新增“考前说明 / 开始或继续作答”。读取考前说明不开始计时；明确确认开始才创建/恢复本人固定答卷，退出不会暂停服务器时间。支持单选、多选、判断、按稳定空格标识填空及主观文字。选择可明确清空，填空和文字保留原文。逐题显示当前一题，交卷核对按 20 条分页，不将整份长卷反复传入视图。倒计时只是服务器时间的本机估计，截止是否封存以真实回执为准。

编辑或重试前明确知情并允许本机暂存。该作答暂存与评语的“只存标识”不同：它按 API/应用/租户/账号/接收人隔离保存逐题草稿、原云端响应基准和完整待确认请求；每个问题独立保存，不含标准答案、解析、教师评分点或私有来源。正文和原图复制逻辑保留 24 小时，在后续使用时检查，不保证应用关闭时物理删除。退出、换号或真实失权尝试清除正文与专用复制，保留必要操作标识供核对；失败单独提示，无法据此认定共享设备已擦除。会话到期先隐藏页面，可重新核验同一账号后继续比较。只有服务器确认的答案保证跨设备恢复。

单图通过 `wx.chooseMedia` 选择/拍摄，按服务端大小、类型与张数限制核对；`wx.getFileInfo` 使用 SHA-256，再检查头部和复制后的字节。不支持或返回弱摘要时阻止上传，不新增加密依赖。原图复制使用操作编号生成的本应用路径，带 bearer/租户发往固定上传接口，multipart 边界由平台生成。上传确认只把图片加入本机草稿；保存本题后才进入服务器答案。替换先保留旧图，直到新图回执确认；旋转、顺序和移除只改响应引用，不改原字节或删除历史原图。原图通过既有授权接口预览并缩放拖动。

开始、保存、上传和交卷在发送前保留原操作；结果未知时先查询，明确重试也先查原回执，再使用同一请求。同一问题的云端响应变化时保留本机草稿，切换查看云端或本机，比较后明确选取基准；另题更新不会自行改写本题基准。云端响应集合 CAS 仍是最终门槛。配额失败保留运行内存并提示，不发送没有操作记录的请求。原图丢失可先查询上传，再重新选择 SHA-256/大小/类型相同的原图；新拍照片不能冒充原请求。过期或退出后已丢失的文字请求正文不能重放，标识本身不表示失败。

交卷可选择“依次同步全部草稿，再核对”，遇到未知回执或冲突立即停止，保留余下草稿。也可先核对服务器逐题保存状态、空白及缺失空格、本机排除草稿和全部未关联上传；历史替换图也可能属于未关联项，不自动标成失败。有排除项必须明确选择“只交已保存部分”，再通过第二次确认。任何编辑或刷新使核对失效。封存回执明确区分手动提交与截止封存；本机未保存内容不随按钮自动上传，关闭客户端后仍由服务器封存确认答案。后台封存不等于已评分，教师统一发布后再按仅成绩/完整讲评查看。

ABP 可能以 403 表达已截止、版本冲突、图片限制等业务拒绝。仅固定测评写入路径及明确业务错误码保留草稿和待确认请求；其他 401/403 仍沿用认证/授权失败规则，不通过该例外开放读取。真实接口已验证手动答卷 48/50、图片替换/旋转、排除项、原操作恢复、后台截止及正式发布。它仍不是微信 SDK、相机、WXML、共享设备、全弱网或完整浏览器点击验收。

## 学生材料学习与上交

学生在当前学校进入“材料学习与我的上交记录”。列表在服务端按学校筛选后计数和分页，不提供正文、不标记接触。明确进入任务使用 `open-my-for-school`，核对本人接收人及学校后才提供当前获准内容；旧 Web 的 `open-my/{recipientId}` 路由保留。未来任务只展示元数据；已截止可以阅读当前材料和反馈困难，不能新开始或完成；换版和撤回只保留本人历史入口。

正文作为纯文本显示。附件 GET 仅支持固定接收人、材料和附件三个标识，委托原应用服务复核当前关系、发布及来源权限；不产生公共 Blob 链接。当前原生预览支持元数据类型和扩展名一致、20 MB 内的 JPEG/PNG/WebP 与 PDF、Word、Excel、PowerPoint 文档，其余类型在网页阅读。图片使用页内视图，文档调用平台 `openDocument` 并关闭菜单；依据[微信官方 API 类型定义](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.api.d.ts)，实际渲染和临时文件行为仍须真机验收。每次预览重新授权下载，隐藏/刷新/换号时清空视图并尝试删除本次自有临时文件；清理或关闭菜单不等于能收回已看到或另存的内容。

开始、完成与困难都是明确的学生记录。完成须有前次开始并确认仅为学习活动；总结或困难文字须勾选共享给本任务教师。困难需要类型和说明；完成后重新开始需要原因。教师私有跟进正文不进入学生接口，只显示对当前困难的处理时间。刷新发现学生修订变化时保留原输入和基准，不自动合并，需核对历史后明确丢弃本机输入并重读。

本页面不暂存正文或附件路径；未上交输入只在本次页面内存，离开或退出会丢失并提供离开提醒。发送前仅按应用、账号、租户和接收人持久化原操作标识；不接受无法保留标识的新写入。响应丢失先查原回执；本次页面仍有原请求时，明确重试也先查再按同号同内容发送。离开或冷启动后原正文不在内存，仅可查询、核对历史或明确关闭本机追踪，不能重造原请求。关闭追踪不撤销云端已经成功的记录。

学校共享撤回后，每次材料正文和下载均受 D03 阻断，旧回执与已上交历史按当前身份继续追溯。已提供的当前任务可明确上交“材料无法读取”困难；不允许借历史重新读取来源或把自报完成当成掌握度。

## 当前学校的统一学习安排
