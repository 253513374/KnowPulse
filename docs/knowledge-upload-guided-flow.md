# 知识上传引导交互流程

## 目标

`/knowledge/upload` 是管理员上传一份知识并确认其可被问答检索的主入口。它面向第一次或低频上传知识的管理员，优先解决“我现在做到哪一步了、哪些内容会进入问答、是否已经发布并索引成功”的理解问题。

当前 `/knowledge/items` 保留为高级知识管理页，用于版本维护、附件管理、权限范围调整、索引任务排障和反馈处理。入口分离原因见 `docs/adr/0001-knowledge-upload-guided-entry.md`。

## 页面结构

页面使用 5 步横向步骤条，主体采用两栏布局：

- 左侧主区域：当前步骤的输入、校验和主要操作。
- 右侧状态摘要：持续显示文档标题、内容来源、可索引状态、可见范围、发布状态和索引状态。

步骤条：

1. 选择内容
2. 知识信息
3. 可见范围
4. 确认发布
5. 索引结果

## 第 1 步：选择内容

目标：让管理员明确这份知识的内容来源，以及哪些内容会进入问答索引。

内容来源分四类：

- 正文输入：直接可索引内容。
- 上传 `.txt`、`.md`、`.markdown`：直接可索引内容。
- 上传 PDF、Word、PowerPoint、Excel、HTML、CSV、JSON、XML：转换后可索引内容。
- 上传图片、音频、视频、压缩包等其他文件：仅附件内容。

推荐交互：

- 使用分段控件切换 `粘贴正文`、`上传直接索引文件`、`上传转换文档`、`上传仅附件`。
- 文件选择后立即显示识别结果：
  - `将进入问答索引`
  - `转换为 Markdown 后进入问答索引`
  - `仅作为附件保存，暂不参与问答`
- 如果只选择了仅附件内容，允许继续，但右侧摘要显示 `当前没有可索引内容`。

主按钮：`下一步：填写知识信息`

## 第 2 步：知识信息

目标：补齐知识条目和版本的基础信息。

字段：

- 标题：必填。
- 分类：可选。
- 摘要：可选。
- 版本标题：默认使用标题，可编辑。

正文来源处理：

- 如果第 1 步选择了正文输入，正文进入版本正文。
- 如果第 1 步选择了可索引文本或 Markdown 文件，文件作为版本附件保存，并由后端直接读取参与后续索引。
- 如果第 1 步选择了转换文档，文件作为版本附件保存，并由后端 MarkItDown reader 转换为 Markdown 后参与后续索引。
- 如果第 1 步只有仅附件内容，版本正文可以为空，但发布确认时必须明确提示“不会进入问答检索”。

主按钮：`下一步：配置可见范围`

## 第 3 步：可见范围

目标：在发布前确认谁可以看到或检索这份知识。

默认值：`全员可见`。该决策见 `docs/adr/0002-default-guided-upload-visibility.md`。

提示文案：

> 全员可见表示有知识库权限的用户都可能检索到该内容。

范围类型：

- 全员
- 部门
- 岗位
- 角色
- 指定用户

选择非全员范围时，显示对应目标选择控件。最低安全等级作为可选高级字段，默认折叠，避免干扰普通上传。

主按钮：`下一步：确认发布`

## 第 4 步：确认发布

目标：让管理员在发布前看到最终影响。

确认项：

- 文档标题、分类、摘要。
- 版本标题。
- 可见范围。
- 直接可索引内容数量。
- 转换后可索引内容数量。
- 仅附件内容数量。
- 发布后会创建索引任务。

如果没有可索引内容，显示醒目但非阻断提示：

> 当前知识没有可索引内容。发布后可在知识库中查看附件，但问答可能无法命中这份知识。

如果存在转换后可索引内容，显示非阻断提示：

> 该附件会在索引阶段通过 MarkItDown 转换为 Markdown。若服务端未安装或配置 MarkItDown，可在索引结果中查看 reader 阶段失败原因。

按钮：

- 主按钮：`发布并创建索引`
- 次按钮：`保存草稿`
- 返回按钮：`上一步`

行为：

- `发布并创建索引`：创建或更新知识文档、版本、附件，发布版本，并创建索引任务。
- `保存草稿`：只保存文档和版本，不进入问答检索链路。
- `上一步`：返回继续修改。

## 第 5 步：索引结果

目标：闭环告诉管理员“是否已经可以去问答验证”。

成功状态：

- 状态：`已索引`
- 说明：`这份知识已完成索引，可以进行问答验证。`
- 动作：
  - `去问答验证`：跳转 `/rag/answer`
  - `继续上传下一份`
  - `查看高级管理`：跳转 `/knowledge/items?itemId={id}&versionId={id}`

处理中状态：

- 状态：`索引处理中`
- 说明：`索引任务已创建，请稍后刷新结果。`
- 动作：
  - `刷新状态`
  - `查看索引任务`
  - `继续上传下一份`

失败状态：

- 显示失败阶段和失败原因。
- 动作：
  - `重试索引`
  - `返回修改内容`
  - `查看索引任务`

## 右侧状态摘要

状态摘要在 5 步中保持固定位置，帮助用户理解当前完成度。

摘要项：

- 文档：未命名 / 已填写标题
- 内容：有可索引内容 / 仅附件 / 无内容
- 可见范围：全员 / 部门 / 岗位 / 角色 / 指定用户
- 发布：草稿 / 待发布 / 已发布
- 索引：未创建 / 待处理 / 处理中 / 已索引 / 失败

摘要不提供主要编辑入口，只提供当前状态和必要的风险提示。

## 菜单与命名

知识库菜单建议顺序：

1. 上传知识：`/knowledge/upload`
2. 知识管理：`/knowledge/items`
3. 分类
4. 标签
5. 权限范围
6. 索引任务
7. 知识反馈

`上传知识` 是主入口，`知识管理` 是高级入口。

## 不做范围

本流程不承担以下能力：

- 批量上传。
- 图片 OCR、音视频转写、压缩包递归解析或复杂结构化抽取。
- 多版本对比。
- 索引任务批量排障。
- 完整 BI 或运营报表。

这些能力继续保留在高级管理或后续增强任务中。
