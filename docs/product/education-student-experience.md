# KnowPulse 学生微信小程序产品规划

> **历史文档／已退役（2026-11-01）**：本文记录早期学校教育方案或当时的实现与验证，学校管理、学校身份核验和旧 `/education/*` 工作区已退出当前产品。文中的“已确认”“当前”及验收结果仅指原记录时点，不作为现行需求或可用功能承诺。当前方向以[教师出题与学生答题业务需求](../business-requirements.md)及[项目改造计划](../project-refactoring-plan.md)为准：教师使用 `/teacher/*`，学生使用平级独立 `KnowPulse.MiniProgram`。

日期：2026-10-06。状态：完整产品设计，原生身份与成绩回顾已部分接入；实际范围及验收见[实施记录](../education-implementation-progress.md)，本文件不表示所列功能已全部实现。
已确认边界：初中、多学科、师生均有微信小程序入口、每个用户拥有个人知识库。总体规划见[教育产品规划](../education-product-plan.md)，教师配套流程见[教师端体验规划](education-teacher-experience.md)与[教师小程序规划](education-teacher-miniapp-experience.md)。

## 1. 产品目标与学生任务

学生端帮助学生知道今天要做什么、可靠完成考试和学习、理解失分原因，并通过订正与复测看到进步。首页不以总分、排名或资料数量作为唯一中心。

| 学生情境 | 要完成的事 | 产品给出的结果 |
| --- | --- | --- |
| 放学后打开小程序 | 找到今天必须完成的任务 | 学科、任务类型、截止时间和下一步清晰可见 |
| 正式考试遇到断网 | 确认答案是否真的交到系统 | 明确区分本机暂存、待同步、服务端已保存和已交卷 |
| 收到成绩 | 知道哪些题需要再学、哪些还在批改 | 展示已开放的评分证据与待处理项，不把待批改计为零分 |
| 收到教师学习安排 | 按可完成的小步骤学习 | 目标、材料、练习、预计用时和复测安排连贯 |
| 积累学习方法 | 保存自己的笔记、订正和资料 | 私有知识库可按学科、教材章节和知识点整理 |

首期服务校内教学，不提供陌生人社交、公开排行榜、广告激励或面向所有问题的开放 AI 代答入口。教师确认的讲解与反馈优先于自由生成的学习结论。

## 2. 身份接入与账号支持

建议入口为学校提供的邀请入口或班级邀请信息。首次使用依次完成微信登录、核对学校学生身份、确认班级与学期、进入待办；微信身份本身不能证明学生属于某班。
绑定采用学校已建立的学生档案与可核验邀请信息，不允许通过姓名搜索自由认领学生身份；页面只展示完成核对必要的脱敏信息。

| 状态 | 学生看到的内容 | 下一步 |
| --- | --- | --- |
| 尚未绑定 | 绑定说明、所需邀请信息、学校帮助入口 | 继续绑定；不得展示班级成员与试卷 |
| 邀请失效或信息不符 | 明确原因与重新获取方式 | 联系学校指定支持人员，不重复创建学生档案 |
| 已绑定其他账号 | 账号冲突提示及申诉入口 | 经学校核验处理，不直接覆盖现有绑定 |
| 学校确认中 | 确认进度与支持入口 | 保留申请；不提前开放任务或学情 |
| 转班、离校或学期变化 | 当前有效身份、待处理关系 | 学校更新关系后重新核验；历史记录按既定策略保留 |
| 登录失效 | 重新登录提示与作答恢复说明 | 重新认证后恢复同一场考试，不新增一次作答 |

个人库在账号确认后幂等创建；重复登录、邀请重复确认不产生多个默认库。更换微信、共用设备、遗失账号与账号合并须有学校支持流程，不能依赖学生自助修改身份标识。
监护人授权或协助、学生设备可用性、学校联系方式与账号恢复责任人为上线前依赖；具体政策由学校和产品方确认。首期不据此扩展独立家长端，也不预先作法律合规承诺。

## 4. 今日：把任务变成可执行的下一步

首页先展示正在进行的考试，再展示当天到期任务和教师明确的优先事项。按学科筛选时保留跨学科待办数量，避免漏掉其他科目；不使用无法解释的 AI 紧急排序。
任务卡包括任务类型、教师、学科、标题、截止时间、状态与主要动作。正式考试、练习、阅读、订正和复测使用文字标签区分，颜色只作辅助。
进入 S03 前不会启动考试计时；S04 明确确认开始后才创建或恢复正式作答。预计学习用时属于提示，与考试强制时限分别呈现。
逾期任务进入“需要处理”，显示可否补交、教师延时或申请帮助；到期不自动视为完成。通知和订阅提醒是辅助，学生不授权通知也能从任务列表完成全过程。
学校撤回或替换任务时展示原因和新安排；已提交结果保留回执，不能从历史列表无提示消失。无任务时引导查看学习资料和个人笔记，不制造虚假的“欠缺学习”。

## 5. 正式考试与练习的规则

| 行为 | 正式考试 | 练习、订正与复测 |
| --- | --- | --- |
| 开始与时间 | 服务端确认开始，采用考试窗口与本次时限中较早的截止时间 | 普通练习可分段完成；复测是否限时由教师明确设置 |
| 作答次数 | 采用教师发布的次数与补考规则；恢复不消耗新次数 | 可允许重做；首答、重练与复测分别记录 |
| 提示与解析 | 开考前说明规则，未开放内容不返回客户端 | 日常练习按任务配置逐题或提交后开放；用于独立证据的复测遵守正式测评规则 |
| 离开页面 | 提醒未同步内容与计时继续；再次进入恢复同一次作答 | 保存进度；暂停或恢复行为在任务详情说明 |
| 交卷 | 展示漏答/未同步项，确认后不可继续修改该次作答 | 按配置提交整份或完成单题；重练新建练习记录 |
| 证据用途 | 符合独立证据规则的已确认评分进入有效测评证据 | 同题重练及看提示/答案后的作答单列，不充当新题独立测评证据 |

S05 提供答题卡和上一题/下一题，已答、未答、待检查、待同步分别可辨。首期按选定学科覆盖单选、多选、判断、填空及基本文本/图片主观题；公式和图片须经真实手机验收。
填空题按空位顺序呈现并说明单位、格式和可接受输入；主观题显示文字或图片要求。录音、视频、复杂手写公式编辑和全自动作文评分不作为首期默认能力。
首次图片作答先说明拍摄范围与清晰度，支持预览、旋转/重拍、替换及按顺序排列。上传成功不等于该图片已作为答案被服务端确认，二者分别反馈。

## 6. 保存、弱网与交卷的可信体验

答案至少显示四类状态：“本机暂存，尚未提交到服务器”“正在同步”“已保存至服务器，时间 ……”“保存失败，点击重试”。无服务端确认不得显示“已保存”。
每题的服务端保存版本决定恢复内容；重试同一保存操作不重复产生答案。跨设备或旧页面版本冲突时提示存在更新版本，让学生核对后恢复，禁止静默用旧答案覆盖新答案。
弱网时保留本机待同步内容并清楚标示；产品内主动退出或清缓存前提示未同步风险。系统清缓存或直接更换设备无法拦截，通过首次暂存说明和持续未同步标记告知本机内容可能无法恢复。恢复保证以服务端已确认数据为准。

切换教师/学生角色前检查本机未同步答卷和草稿，先同步，或明确提示风险并让用户选择处理方式；保留内容按身份隔离，不静默丢弃，也不向另一角色展示。考试计时在角色切换期间继续，返回学生身份后恢复同一次作答，不能通过切换角色重新开始或延长考试。
图片分项显示上传/失败/已确认；失败可逐张重试，不要求重新填写整题。临时上传内容按当前用户和作答隔离，未确认附件不能出现在教师收到的有效答案中。
交卷前汇总漏答题、未完成上传和未同步题。存在待同步项时优先继续同步；学生仍选择提交已保存部分时，须明确告知哪些内容将不计入并再次确认。
提交无响应时显示“正在确认交卷结果”，查询同一次作答的服务端状态；禁止只因请求超时显示交卷失败或立即创建新作答。重复点击交卷最终只有一份有效回执。
倒计时以服务端截止时刻为准，设备时钟变化不延长考试。到时服务端封存截止前已成功保存的答案并完成可重试的后续评分；小程序离线或关闭不阻止封存。
到时后的本机暂存不得伪装成已按时提交；页面列明未纳入内容，并可通过学校支持流程申请处理。补考、延时或重新开放须由教师明确操作并留痕，学生端不能自行延长。

## 7. 成绩开放、待批改与反馈

首期结果可见性统一为“隐藏 / 仅成绩 / 完整讲评”，由服务端依据教师规则控制，不能靠前端隐藏。考试列表、开考、保存、恢复和成绩响应的嵌套对象同样不返回未开放内容或私有题源。
成绩开放时间与完整讲评开放时间可独立配置；标准答案和解析在完整讲评时一同开放，评分要点遵循同一讲评权限。错题收藏另行授权；日期到达不应越过批改状态、撤销状态或其他规则。学生收到清晰的预计开放说明，教师变更时显示最新状态。
含未批改主观题时显示“已交卷，等待教师批改”；首期正式任务须提交窗口结束、进行中答卷封存且有效提交集合固定，再完成全部应批改项目后按任务统一开放最终成绩，缺考、取消和正式豁免分别记录，不展示临时客观题分数。仍有人可开始、继续或追加尝试时不开放完整讲评。教师端可查看临时批改进度，学生端仅显示等待状态；未批改题不计零分，也不计入掌握度。
S07 在仅成绩阶段显示已开放最终成绩，在完整讲评阶段逐题展示本人答案、评分、标准答案、解析、教师评语、对应知识点和可执行的订正动作。学生可提交题目问题或评分复核申请；申请处理中保留原成绩并显示状态，正式修订后注明版本和理由。
题目被判无效或考试撤销时，成绩和成长页同步显示重算/已更新。尚未完成重算期间不得混用新分数与旧知识点结论。

### 教师评语

学生在 S17 查看教师从网页或小程序对本人发布的日常、任务及阶段评语，展示教师、学科、对应时间/任务和最新有效正文。教师草稿及私有观察不返回学生端；绑定测评的评语随完整讲评开放，不能绕过成绩与解析规则。

日常和阶段评语只有在不包含未开放测评事实或私有来源时独立开放；涉及该类证据则等待对应测评的开放条件。评语卡片和通知预览遵守相同规则，未开放时不提前显示正文。

实际打开当前版本后才能记录已读，不以收到通知、未读数消失或应用前台运行代替阅读；不要求学生点赞或立即回复。更正标明已更新，已撤回正文不再显示；撤回前的本地预览按当前权限失效，但不能承诺撤销已经被人看到的内容。学生仍可从帮助或关联任务向教师反馈理解困难。

收到评语不自动增加或降低知识点掌握度；只有符合分析口径的学习证据影响估计。教师的学生评语也不自动复制进学生私人笔记，学生主动整理时保留当前授权边界。

## 8. 学习材料、错题与个人知识库

S08 将“老师安排”和“我的积累”分开呈现。阅读完成只说明活动完成；收藏、停留时长和点击“学会了”均不直接提升知识点掌握度。
教师布置的材料仅开放指定版本及必要附件；学生可读某份材料，不代表能进入教师个人库、查看引用教案或搜索该教师全部资料。授权失效时展示原因和联系教师入口。
学生个人笔记默认私有，教师、同班学生和学校成员不因角色获得查看权。教师要求上交的订正是独立教学记录，提交前列明上交内容；私有笔记不能被自动夹带。
S11 支持按学科、教材章节、知识点和自定义标签整理；笔记可保存文本及首期支持的图片/附件。自动推荐标签需要学生确认，跨学科同名知识点不合并。
错题先作为考试回顾入口，题目达到教师开放与收藏条件后才允许收录；不能提前把未开放标准答案、解析或题源复制入个人库。只开放题干时可记录自己的思路，仍不补全受限字段。
收藏需标明来源任务、题目版本和当前授权；对仅获浏览授权的材料采用引用入口，不能自动变成永久副本。D03 已确认：学校共享撤回后，已布置或曾打开的材料也停止后续在线正文/附件读取，显示受阻及困难反馈入口；历史答卷和已上交记录按各自权限保留，不能通过历史记录重新读取原资料。既有冻结考试及结果规则独立适用，不声称能收回已看过或下载的内容，见 ADR 0029。
订正可记录“我原来怎么想”“现在如何解答”“下次怎样检查”，避免强迫学生选择“粗心/懒惰”等人格标签。完成订正后引导间隔复练或教师布置的新题复测。
学生删除个人笔记不等于删除已提交考试、评分和教师收到的作业；页面说明两类记录的区别。导出仅包含本人内容与已获导出授权的素材，账号迁移和离校留存政策在上线前确认。

## 9. 成长、个性化安排与复测

S13 先按学科呈现近期目标与证据概览，再下钻知识点；不把多个学科分数混成一个学习能力分。对“未测评”“证据不足”“需要巩固”“达到当前目标”给出不同解释。
每个掌握估计显示测评题数、最近时间和查看证据入口。图表是阶段性估计，不宣称诊断学生能力；学生不必先理解复杂统计术语才能找到下一项学习任务。
成长概览只纳入已向学生开放成绩的测评，逐题依据仍需完整讲评权限；待公布结果不能通过掌握度变化、错题标签或消息提前泄漏。因范围限制暂不可看时说明原因，不将隐藏证据显示成零分。
S14 仅展示教师确认并下发的方案版本：学习目标、原因、材料、练习、预计负担、截止时间、复测与成功标准。教师内部草稿及未经核实的 AI 原因推测不向学生直接发布。
方案任务可包含阅读、例题理解、针对练习、订正和复测；学习材料不可用时标记受阻并反馈教师，不要求学生以虚假完成绕过。学生可报告“看不懂”“时间不足”“材料打不开”。
方案变更显示修改内容与未完成安排，已完成的有效活动保留；教师暂停或终止方案时同步停止后续提醒。多个学科方案集中展示时间负担，冲突由教师协调，不由学生承担系统性冲突。
S15 用于更新独立测评证据与完成教学闭环的复测须使用同知识点的新题，遵守正式测评的答案开放规则；原题复练单列，不能增加独立证据量。阶段回顾并排呈现可比较证据与任务完成情况；范围或难度不同则说明限制，不把涨分直接归因于方案。
学生反思可作为个人笔记私存，或明确提交给教师；两种动作使用不同按钮。复测后由教师决定继续、调整或结束，系统不能仅凭阅读完成自动宣告目标达成。

## 10. 通用状态、可访问性与学生尊严

| 状态 | 统一处理 |
| --- | --- |
| 空状态 | 说明为何没有内容，给出有效下一步；未测评不显示红色零分 |
| 加载或后台处理中 | 展示当前动作，避免重复点击；长任务可离开后查看状态 |
| 网络、资源或服务错误 | 保留输入，解释可重试与需联系教师的区别，不暴露内部日志 |
| 待审核、待批改、待开放 | 显示状态、可做事项与预计安排；不伪造完成时间 |
| 逾期、撤回或权限变化 | 说明原因和可补救动作；已经提交的回执可追溯 |

正式答题采用足够大的点击区域、清晰焦点与输入标签，支持系统字体调整；题目状态同时使用文字/图标，不只靠红绿颜色。公式和图形提供适当阅读说明，放大不遮挡提交区域。
图表提供文本摘要，主要操作可被辅助阅读识别，减少动态闪烁和强制动画。图片加载失败须能重试；无替代说明会影响理解的题目应由教师修订后布置。
默认不公开排名、不显示同学成绩，不以连续打卡断签、倒计时恐吓或负面标签施压。反馈描述具体题目与学习策略；“需要巩固”不等于对学生作能力定性。
共用设备退出后清除可恢复会话及按策略处理本机缓存，再次进入重新核验身份；不在锁屏通知里展示分数、薄弱项或其他敏感学习内容。

## 11. 教师端与学生端交接契约

| 教师动作 | 学生端收到 | 必须共同遵守的约束 |
| --- | --- | --- |
| T14 发布任务 → S03/S04 | 固定版本、学科教材范围、对象、时间、规则、教师身份 | 分配对象基于有效关系；发布后修改按版本规则处理 |
| 布置学习资料 | 指定版本的可读材料与学习要求 | 学习授权不扩展至教师库或私有题源 |
| T17 发布/调整成绩规则 → S07 | 当前开放状态与解释 | 服务端字段裁剪；缓存遵守当前可见性与账号隔离，未开放信息不下发、不缓存 |
| T16/T17 人工评分或复核 → S07/S13 | 已确认评分、评语、修订提示 | 待批改不计零分；修订同步更新证据及成长页 |
| T21 下发个性化方案 → S14 | 已确认目标、任务、复测、成功标准 | 不下发 AI 草稿；私有教师准备内容不随方案泄漏 |
| T25/教师小程序发布评语 → S17 | 对本人已开放的日常、任务或阶段评语 | 草稿与内部观察隔离；任务评语遵守完整讲评规则；已读按版本记录 |
| T15/T22 处理困难、撤回或补考 → S03/S14 | 明确的新安排与处理状态 | 保留历史回执；不静默丢失已提交记录 |
| S06/S10/S15 学生提交 → T16/T19/T22 | 教师收到有效提交内容及保存/提交时间 | 不夹带个人私有笔记；重试不会重复记分或累计证据 |

## 12. 分阶段交付与验收

M1 完成身份、学校班级与任教关系、个人库和基本共享的后端基础，包含学生私有库归属与隔离；此阶段不承诺学生小程序已可使用。M2 完成教材、AI 出题审核及试卷，学生题目预览依赖由教师侧准备。M3 交付学生小程序入口、个人学习积累、考试学习、人工批改与逐题证据。M4 交付掌握度、教师确认方案与复测；四阶段共同构成完整首期。

1. 两名学生绑定不同档案，伪造任务或知识库标识仍不能读取对方内容；教师无法读取未授权个人笔记。
2. 邀请过期、重复绑定、身份待确认、转班和登录失效各有恢复路径；重复操作不产生重复个人库或考试记录。
3. 断网填写文字、上传图片失败后重进，恢复内容与服务端已确认答案一致；未确认内容始终有可见提示。
4. 提交超时后重复点击、页面退出、服务器到时封存最终只形成一份有效提交；迟到数据不被记为按时保存。
5. 未开放阶段检查所有学生响应和缓存，不含标准答案、评分要点、受限解析和私有题源，包括嵌套对象。
6. 含主观题考试从已交卷进入待批改，完成评分后按规则开放；复核修订同步成绩、证据与知识点展示。
7. 至少覆盖首批多个学科、实际教材公式/图形和所选题型的真实手机流程；图片失败与辅助阅读场景纳入验收。
8. 一个学生完成“考试—查看开放结果—订正—教师方案—学习—新题复测—阶段回顾”；阅读不直接改变掌握估计，同题重练不虚增独立证据。
9. 材料授权撤回、任务逾期、方案变更与无效题重算均有清晰状态；任务链接不能绕过本人分配校验。
10. 私存笔记与提交反思的按钮、提示和教师端结果一致；退出共用设备后其他账号不能恢复上一位学生的私有数据。
11. 教师从手机发布给指定学生的评语仅该学生可读；待开放内容、教师观察和草稿不会进入正文或通知预览，更正与撤回在各入口一致生效。

上线前须落实首批学科教材、真实学校身份核验流程、账号支持责任、图片限制、成绩开放规则、设备覆盖和网络场景。试点同时观察任务完成率、保存失败率、交卷重复率、批改等待与复测完成情况；目标数值经基线验证后确定。
