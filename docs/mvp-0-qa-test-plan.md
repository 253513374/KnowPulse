# KnowPulse MVP-0 QA 验收测试计划

版本：v0.1  
日期：2026-06-25  
对应任务：`KP-MVP0-QA-001`、`KP-MVP0-QA-002`、`KP-MVP0-QA-003`、`KP-MVP0-QA-004`

## 1. 范围

本计划覆盖 MVP-0 的本地开发环境、组织基础数据、知识库生命周期、权限范围、前端状态、文件上传下载和审计日志。

不覆盖真实 RAG、向量索引写入、AI 出题、考试、学习记录和生产级部署。

## 2. 前置条件

- 已执行 `docker compose up -d`。
- 已执行 `.\ops\health-check.ps1` 且 PostgreSQL、MinIO、Qdrant、LiteLLM 健康检查通过。
- 已执行 `dotnet run --project .\src\KnowPulse.DbMigrator\KnowPulse.DbMigrator.csproj`。
- API Host 和 Blazor 已启动。
- 测试账号至少包含：
  - `admin`：拥有 MVP-0 所有管理权限。
  - `dept-a-user`：属于部门 A，安全等级 1。
  - `dept-b-user`：属于部门 B，安全等级 1。
  - `secure-user`：属于部门 A，安全等级 3。

## 9. 通过标准

- P0 用例全部通过。
- 所有 403 场景由后端 API 强制完成，不依赖前端隐藏按钮。
- 审计日志能定位操作人、时间、服务方法和结果。
- 审计日志不保存知识正文和文件原文。
- 未通过用例需记录阻塞原因、复现步骤和关联任务编号。
