## 1 已确认的产品基线

- 初中、多门学科；每个业务用户有默认个人知识库。
- 教师资料默认私有，主动共享指定版本到学校；学校成员、管理身份及任教关系不自动授予私人资料阅读权。
- 教师网页承担复杂整理、出卷、批改和方案确认；教师微信承担简单工作、数据查看和学生评语；学生微信完成学习、考试与反馈。
- 一个 AppID、教师与学生两套独立工作区已于 2026-10-18 由用户确认；实际主体、认证、合法域名、上架及平台条件仍待接入核验，本阶段先完成代码与本地验证。
- 题目经人工审核，正式测评在提交窗口结束、进行中作答封存、有效提交集合固定且评分完整后统一发布。完整讲评不能在仍可作答时开放。
- 教师观察默认作者私有；学生评语按接收人、证据与开放条件展示，更正、撤回、通知和按版本阅读分别记录。
- 知识点估计基于全量有效评分证据；原题复练与独立新题复测分开，教师确认教学方案，复盘不宣称未经验证的因果提分。

PRD 已修正早先的窗口开放、M2 真机出口、M1 上传限制、新题复测及 AC26 分阶段恢复问题。本轮没有发现需要重新扩大产品范围的缺口。

| D01 兼容迁移 | 新个人数据使用明确归属；存量组织数据不自动据 CreatorId 改为私人资产。新增字段/映射/迁移同步，先验证空值与存量兼容。 | 已完成真实生产数据归类或账号迁移。 |
| D03 共享授权 | 授权以学校、具体资料版本、用途与有效状态表达，撤回在数据库检查时阻断新使用；共享不复制成永久个人资产。用途未授予则拒绝相应动作。 | 已有任务、下载副本和衍生作品可以被完整收回；学校已接受留存或继续交付政策。 |
| D04 资料上传 | 沿用已有转换边界，服务端与 UI 使用同一可配置格式/数量/大小校验；当前已验证文档与仅附件分别显示；超限保留草稿。开发/测试参数标明其环境用途。 | 已采购教材、扫描件可可靠 OCR、某个上传额度是客户承诺。 |
| D06 归档与导出 | 私有导出仅自有或明确允许的内容；归档、撤回、删除请求与实际物理清理分开，保留必要教学事实；不自动转移作者个人资产。 | 最终留存年限、离校历史访问、全量物理删除及监护人安排已确定。 |
| D09 基础容量 | 实现可配置容量与上传限制、任务健康/失败观测、备份与恢复路径；本地测试给出实际负载和结果。 | 学校并发承载、P95/RPO/RTO 或成本 SLA 已达标。 |

学校模型与租户保持区分是建议的可实施基线，不能消除 D01 的真实接入信息需求。跨租户个人库转移、资产归属变更等影响较大的动作在规则明确前不自动执行；同租户内显式学校关系、个人库和隔离可继续开发。

索引实现可复用现有 worker、接口、阶段、重试和审计，不需要因教育需求拆分微服务。个人内容“准备可用”不得绕过 ADR 0005/0006 的持久化、失效、任务幂等及完整索引边界，也不得借默认全员策略公开。

## 5 可立即执行的实施路线

1. **个人库归属与默认初始化。** 建立显式所有者与默认库唯一性，扩展条目归属、契约、EF 映射与迁移；为同一账号重复及并发初始化、宿主空租户、存量组织条目兼容建立测试。
2. **贯穿已有入口的私人隔离。** 统一个人条目所有者写权限、版本级读权限；覆盖列表、详情、附件、旧高级操作、权限范围、索引、RAG 和生成衍生内容。普通教师、另一用户、学校管理员均作为负向场景，不仅使用管理员身份。
3. **本人可检索与资料版本。** 接通私有准备、索引 worker、状态与恢复；复用当前组件构建网页个人库/详情入口。验证未共享资料本人可以检索，失败保留草稿并有修复路径。
4. **学校基础与选定版本共享。** 建立成员、班级学期与任教关系基础，支持明确范围与版本的共享/撤回；重点验证 R03 的 v1/v2 隔离，向量过时仍由数据库阻断，未授权素材不被导出。执行 EDU-M1 的 AC01–AC05、AC25 及 AC26 基础部分。
5. **教材与出题。** 在 M1 所有者和版本范围上增加稳定教材/知识点、结构化出题范围、审核与冻结；采用真实获准样本完成 EDU-M2 双视角验收。不能只给 prompt 增加教材标题。
6. **微信任务及测评。** 接通真实绑定、名单、保存冲突、图片、截止后台封存、人工批改和全量证据，先消除 R05 后再开展学生试点；补教师移动催办/基础分析/评语及跨端版本。EDU-M3 执行三档响应字段与真机弱网验证。
7. **分析与个性化方案。** 基于 M3 全量证据计算可重建投影，接入移动明细与学生开放视图，教师确认方案并新题复测；EDU-M4 完成重算/投影恢复及两学科完整闭环。

上述是依赖路线，不是工期承诺。最早可交付个人库隔离的纵向切片；该切片有明确可审查代码、迁移与测试，但仍是 EDU-M1 的阶段成果，不能当作完整教育产品已完成。

## 6 验收与发布结论

- **产品基线：有条件通过。** FR/US/AC 追踪、双角色分工、三档结果、状态独立性、全量证据和阶段恢复定义足以继续实施。
- **EDU-M1 开发：可启动。** 当前工作应落实归属决策和 R01–R04，先完成可逆模型与隔离闭环；政策和容量参数作为配置/上线门槛保留。
- **教育共享真实上线：尚未通过。** 必须补齐 D01/D03/D04/D06 对应规则，完成版本隔离、权限、恢复及兼容验收。
- **学生真实试点/正式测评：尚未通过。** 当前映射和范围缺口是确定的阻断项，需 M3 全套字段裁剪、截止封存、真机和关系核验。
- **完整首期：尚未完成。** 需要 EDU-M1–M4、多学科真实教材样本、两学科完整教学周期以及对应 NFR 与待决策结论。

本轮执行的是文档与关键代码只读审查，未运行构建、自动化测试、数据库迁移、真实服务、微信接入或学校试点；现有历史通过记录不能作为本轮发布依据。
