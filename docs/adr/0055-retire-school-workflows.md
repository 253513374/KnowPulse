# ADR 0055：退出学校教育流程，保留教师出题与学生答题闭环

状态：已接受，2026-11-01。落实用户再次确认的“不建设学校管理”及本次代码清理要求。

## 当前产品边界

以 [2026-10-23 业务需求](../business-requirements.md)为准：教师在 Web 整理个人资料、使用获授权的共享资料出题、确认题目并向自己的指定学生发布任务；学生使用独立的 `KnowPulse.MiniProgram` 答题。邀请码申请和教师确认建立轻量师生关系，不要求学校成员、任教、学期或在班关系，也不要求教师资格认证。

合并进当前分支的学校教育实现不属于这条产品主线。本决定取代 ADR 0007（学校共享版本）、0008–0052 中有关学校工作区、学校共享、学校课程和教育任务产品入口的适用范围；这些文档仅记录历史设计。ADR 0007（教师归属与固定学生指派）、现有账号与微信绑定安全约束、ADR 0053 的公开账号帮助继续有效。ADR 0054 的品牌登录流程保留，首页无业务权限时的落点改为 `/workspace`。

## 代码清理

- 删除 `/education/*` 学校教育页面、学校共享界面、导航及学校配置分支，教师保留 `/teacher/*` 五个主要入口。
- 删除学校教育应用服务、公开接口、专用附件控制器、后台任务及公开权限组。没有教师或管理功能权限的账号进入 `/workspace` 查看账号帮助与学生小程序说明，不再读取学校身份。
- 删除主仓库内依赖学校工作区的旧 `miniprogram/` 工程；保留同级独立 Git 仓库 `KnowPulse.MiniProgram/`，避免两套学生端并行。
- 删除对应旧业务接口与页面测试，保留当前教师闭环、数据隔离及历史来源授权检查，并验证学校 API 不再暴露。

## 数据与授权边界

本次不执行数据库迁移或数据清理。学校相关实体、EF 映射、既有迁移和冻结快照保留，避免后续迁移意外删表，也不重写已有资料、题目、任务、答卷或成绩。既有学校教育后台作业随其运行入口退出，不再继续推进。

仍被题库、考试、AI 出题、RAG 和私人笔记使用的来源、账号及课程守卫继续保留；旧学校共享的有效性必须按原事实核对，不能因移除学校管理而扩大私人资料访问权。它们是历史记录兼容与授权校验，不提供新的学校管理流程。若未来单独清理历史数据模型，需要明确存量数据迁移和保留方案后另行实施。
