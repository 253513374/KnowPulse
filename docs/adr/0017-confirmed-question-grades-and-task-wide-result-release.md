# Preserve grading revisions and release final results for the whole assessment

Date: 2026-10-14. Status: accepted for implementation; actual verification is recorded separately.

Grading reads the unique submission manifest, exact original response revisions and frozen paper rules from ADR 0015/0016. It never reads a student's later current answer or a teacher's current source question. A concrete internal processor creates one grade root per submitted paper question, including correct and unanswered questions. Automatic parts are scored from the frozen rules; manual blanks and subjective points remain pending. Repeated processing cannot replace a teacher's draft or confirmed version.

Each stable save or confirmation operation creates an immutable grade revision with its original request fingerprint, observed concurrency stamp, response reference/hash, frozen definition and calculation versions, parts and feedback. Confirmed revisions contain complete knowledge-point evidence. Draft and confirmed pointers are separate. A new draft cannot change a student's official score; correcting a confirmed grade requires a reason and preserves the old revision.

Teacher writes acquire School, teacher account, assessment Task and grade roots in that order. Current teaching authority is checked without requiring a new textbook selection or new-use source authorization. Background derivation uses recorded tenant and submission facts, grants no reading authority and contends on Task before grades. Student start also contends on Task and checks the final server UTC time; closing cannot race a late new attempt into a supposedly fixed submission set.

After natural deadline, an explicit teacher operation seals all started attempts through the shared submission processor and freezes every original recipient as a specific submission or absent. Absence is not a zero-score paper. A task can release final results only after this closure and complete confirmed grading for every question of every valid submission. A release freezes per-submission grade revision references and totals, with separate score and full-review times. Configured task rules alone never publish a result; changes require explicit confirmation.

A confirmed correction after publication creates replacement release items and switches the official release pointer in the same transaction, preserving previous scores and reasons. Student queries follow only that pointer. Hidden responses contain no scores or answers, ScoreOnly contains final totals, and FullReview contains the student's frozen per-question answer, rubric and feedback. Private material provenance and internal curriculum mapping identifiers are excluded. Existing task and attempt response surfaces remain safe; a new dedicated result surface controls review content.

New score-review requests refer to a student's own current released result and require that result to be open. They acquire the existing School/account barrier before rechecking the current release, so a superseded release cannot bypass a later hidden result. Committed requests retain their original retry receipts even after a replacement release. Teacher resolutions are retained; an open case does not remove the original official score. Resolution feedback remains hidden until full review. Raw responses, grading feedback and review reasons are excluded from generic audit serialization; business operation identifiers and controlled fingerprints remain available.

Six persistence types cover question grade roots, grade revisions, task closure, result releases, per-submission release items and score-review requests. Stable parent-pair foreign keys and unique operation/sequence indexes enforce associations; mutable task counters are not principal keys. Decimal checks explicitly cast numeric values so SQLite's text decimal storage does not compare marks lexicographically. Existing enterprise exam plans, scores and answer normalization keep their previous behavior.

Default closure follows the natural deadline. Additional attempts, early closure, extra time and invalid-question scoring remain separate policy decisions under PRD D07. Real WeChat pages, device acceptance and the remaining analysis/teaching-plan loop are not established by this grading implementation.
