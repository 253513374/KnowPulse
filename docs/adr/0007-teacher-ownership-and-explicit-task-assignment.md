# 教师资料默认私有，任务按固定学生名单授权

教学产品采用显式教师归属，新的资料、题目、出题任务和答题任务由服务端绑定当前教师；其他教师不能借同一角色读取或修改。此决定在教学入口替代 ADR 0002 的默认全员可见，并收紧 ADR 0005 中空策略兼容的适用范围：未核对归属的历史记录仅进入受控维护范围，不按创建人自动迁移，也不自动公开给新教师。资料自用处理与指定教师共享分离，沿用 ADR 0005 的原子发布和 ADR 0006 的真实索引完成规则。

师生关系只决定未来可选学生。发布必须展开并固化有效接收名单，同时保存题目和评分规则快照；空名单拒绝，新关联学生不补发历史任务。复用现有 Exam 作答和评分，实现可空时间与时长表达真正不限时，学生响应按作答阶段和结果规则裁剪，教师只查看本人任务的结果。微信登录扩展现有 OpenIddict，服务端验证 code 并绑定稳定 Identity 学生账号，不建立第二套本地身份或计分体系。

邀请码申请后教师确认、一次正式提交、默认只显示分数是本轮核心闭环采用的设计默认值，仍保留为业务建议；生产发布前核对最终业务规则。既有数据不做批量归属回填、不补历史指派，生产迁移前另行清点、备份及检查重复指派。
