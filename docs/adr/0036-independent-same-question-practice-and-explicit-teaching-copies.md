# Same-question practice seals a separate teaching copy

Date: 2026-10-18. Status: implemented for Web/service verification; device and full product acceptance remain separate. Extends FR27 and ADRs 0015, 0017, 0019 and 0033. Does not change D03 source-material withdrawal or D06 school exit policy.

An authorized student can start another round for a question in their own current full review. Each round fixes the actual recipient, published task revision, sealed original submission, result release, confirmed grade revision, frozen paper question, original question and definition revision. The current student membership/enrollment and original teacher relation are checked; a replacement release or grade does not silently rebind an old round. Practice reuses the authorized frozen question, stores no second source body and creates no wrong-question collection or export grant. AllowWrongQuestionCollection retains its separate collection semantics; practice does not create a favorite or a permanent source copy.

Starts return only a body-free operation receipt. An unfinished detail supplies the existing answer-free student question projection, with no original response, answer, rubric, automatic mark or teacher-private provenance. Lists and operation/image recovery return only scoped metadata and do not deliver feedback or record exposure. The student edits text, stable choices, blank identities and selected uploaded image references. Browser session state is private local draft/receipt storage, scoped by tenant and account, rather than confirmed cloud work; original binary files are not persisted in that session storage. Unknown commands retain their exact operation/payload/fingerprint. Clearing a local receipt requires an explicit warning and never rolls back a saved server fact.

Before submission, the server validates the actual frozen response shape, selected confirmed image ownership/bytes/hashes and current exact source. Its preparation fingerprint binds that response, image references/order/rotation, session concurrency stamp, release and grade. Explicit confirmation shares the checked response and selected originals with the original task teacher as a separate immutable teaching copy. Starting a round, uploading or previewing does not share draft text or unused images. A round seals once; repeated commands recover the original receipt, different commands cannot replace it, and a new repetition needs another round. Teachers cannot enumerate unfinished rounds or download unselected/private uploads.

The existing frozen scoring calculator handles objective automatic rules. Practice stores a reference evaluation with controlled part IDs and amounts, without curriculum mapping identifiers. Subjective and manual blank parts remain null, and an incomplete automatic total is null rather than zero. The student receives criteria/reference feedback only on an actual submitted-detail read while the same current full-review/grade gates remain valid. That answer-bearing read holds the School/account and result mutation barriers and records only the actual question exposure, preserving its first time. Teacher reading never records student exposure. Submit/operation receipts themselves contain no feedback, so a saved response whose feedback delivery failed can be recovered independently.

Practice never inserts a formal assessment attempt, original response, official grade, release, independent evidence or mastery estimate. The original formal encounter and recorded exposure continue to determine future independence. Original result and teacher report evidence must remain unchanged when only repetitions are added. Student and teacher views present these records separately; any automatic practice mark is clearly labelled a practice reference. This slice does not add a teacher practice-grading or feedback-revision workflow; existing explicit correction/review tasks remain distinct.

Own submitted responses and original uploaded images remain traceable under their own current actor/tenant/school relation when the source gate closes. Source question, criteria and evaluation are then withheld and new execution is blocked; a receipt is not a new source grant. The original teacher needs current assessment/learning management permissions and the recorded teaching/student relations; administrators and other teachers do not bypass ownership. School departure retains the existing fail-closed history policy until D06 is settled. A self-written notebook is a separate account asset, and personal-library export does not include practice teaching records.

Two relational tables persist the round/sealed copy and private image reservations. Paired Restrict source/student foreign keys, a unique submission operation, root compare-and-swap and complete/null submission constraints protect these facts. Migration 20261017204029_AddIndependentQuestionPractice backfills no past repetitions and refuses downgrade once a practice or image fact exists. Reservation, bounded original Blob storage, validation and confirmation are separate; unfinished reservations remain private. Current development limits match correction images: five selected images, 5 MB each, forty reservations/20 MB per round. They are not a school retention or production capacity commitment.

History queries filter current recorded student authority before count/pagination and recheck each returned record; they do not silently truncate years of history to a fixed candidate count. Teacher pagination filters only explicitly submitted copies from the owned original submission. All practice responses/files use private/no-store and private command/body types are excluded from generic audit parameters. No external model is called. Full logged-in browser/device/WeChat, production load, real-provider fault timing and school retention/exit acceptance remain separate from compilation and SQLite tests.

The independent reference-only collection action is specified in [ADR 0039](0039-reference-only-student-question-collections.md). Starting or handing in practice still does not automatically create a collection, and collection permission never replaces the source gates above.

The native workflow, school-checked entrypoints and pending-receipt/explicit-feedback separation are specified in [ADR 0040](0040-native-practice-with-scoped-reads-and-explicit-feedback.md). Original start/submit fingerprints and existing Web routes remain compatible.
