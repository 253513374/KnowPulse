# Preserve teacher evidence, original-relation and hint-context decisions

Date: 2026-10-17. Status: accepted for implementation; report integration remains required.

ADR 0019 separates an independent observation from a confirmed score. The teacher now reviews a real question-grade root and its immutable submission/frozen definition. A qualification defaults to unverified. Declaring independence requires explicit checks for original relationships, new assessment requirements and no answers/hints, plus a reason. Practice, invalid evidence and unverified remain distinct. Invalid evidence excludes this observation from analysis; it does not cancel an assessment, rewrite a grade or implement PRD D07's invalid-question policy.

Three concrete aggregate/revision pairs retain qualifications, known original relations and feedback hint reviews. Current pointers use optimistic concurrency; revisions retain their stable operation ID, fingerprint, previous revision, author, reason and UTC time. A retry recovers its original revision before checking a new write's expected version, without rolling the current pointer back. Reading/recovering still requires current account and teaching authority. A first write explicitly observes an absent root; a concurrent created root cannot be silently overwritten.

A qualification binds the stable grade identity, student, unique submission, paper question and definition. Correcting a score for the same frozen answer does not rewrite or duplicate its qualification. A future report source includes both current score and qualification revisions. The decision itself does not guarantee inclusion: the calculator still applies complete attempt history, known groups and recorded exposure. Missing delivery/history metadata is never treated as proof that no answers were seen.

Original relations are canonical unordered pairs within one owner, school and subject. They retain both exact frozen definitions and source grade references. Both sources require current grading authority, including the exact sources recorded in a recovered receipt. Another eligible grade pair for the same originals does not grant access to an unavailable recorded source or its reason. Writes contend on their distinct Tasks in sorted order after the common School/account barrier. Candidate pages scan real graded questions for the same student in the same school/subject, provide a next scan offset, and reauthorize every returned source. Removing a mistaken relation appends a disabled revision; it does not erase the old decision or assert that all other relationships are known. The grouping used for analysis is metadata, not permission to read another teacher's questions or answers.

Only delivered linked feedback can receive a hint-context decision. Actual full-review exposure cannot be cleared. A hint review binds the exposure's exact student and published feedback revision, and the review UI shows that historical text and the exposure's frozen question/rubric. Later edits or withdrawal do not replace the delivered version being examined. An explicit exact-context confirmation and reason are required for each new review. Unverified, confirmed hints and confirmed no hints remain separate; a no-hint result affects only this context and does not clear any other recorded exposure.

All eleven operations require AssessmentManage plus ownership/current teaching scope. Hint text, hint writes and their recovery additionally require FeedbackManage and the existing feedback recipient authority; another teacher or a former/disabled recipient does not gain access through an exposure identifier. Writes use the existing School/teacher/Task barrier; hint writes also contend on the student's account and recheck feedback authority before persisting. The page stores the exact typed command before sending, scoped by tenant/account/grade, and validates that scope when restoring or retrying. A failed retry of an unknown operation retains the original command.

Six tables retain the roots and immutable revisions. Nineteen Restrict foreign keys pair stable grade/student/owner facts, definitions, delivered student, feedback author/version, source grades, previous revisions and current pointers. Mutable revision counters are not principal keys, and legacy nullable paper-definition references remain nullable. Semantic checks such as feedback source kind and its exact exposure/version association also remain explicit domain/application checks; database parent associations do not replace them. Reasons, context text and these write inputs are excluded from generic audit serialization.

These decisions feed the existing calculation values but are not a persisted teacher report or a student growth view. Authorized source collection, versioned subject rules, report jobs/recovery/atomic snapshot switching, invalidation/recalculation, score-open student projections, personalized plans and new-question reassessment remain required. No school threshold or independent performance claim is inferred from completing this workflow.
