# Student question collections retain references without extending source access

Date: 2026-10-18. Status: accepted for implementation. Implements the collection part of FR27; practice remains the separate workflow in ADR 0036.

The existing enterprise wrong-question entity belongs to another assessment model. Education collections therefore use actual education recipients and frozen paper-question identifiers rather than translating them into old exam facts. A collection saves no stem, answer, rubric, image, original question body or private provenance. It does not label a question as objectively wrong, export its source, create practice, alter an original response or grade, or add learning/mastery evidence.

New collection requires AssessmentParticipate and LearningParticipate, the student's active account and exact current school/enrollment/membership relation, current recorded teacher authority, the current full-review release and confirmed grade, and the frozen task revision's explicit AllowWrongQuestionCollection flag. An expected release prevents a stale selection silently binding another release. Reading body-free state/list/receipts never supplies source content or records exposure. Opening the original result uses its own current gates; a collection cannot reconstruct hidden or score-only feedback. Current availability is recalculated, not a permanent grant from the collection date.

Cancellation requires the same current student ownership and school relation but remains possible when the source gate or recorded teacher availability closes. Collection history does not supply former-school access; D06 remains unresolved. Teachers, administrators, other students and other tenants gain no collection access from knowing identifiers. Account/functional authority and relevant returned-record relations are checked again before returning metadata.

One immutable event table records collect/remove transitions. Each event has an operation ID, positive per-recipient/question revision, previous operation, student/task/paper/source references and a controlled request hash/time. The first event must collect; repeated same-state commands are invalid. A new event must match the expected current operation under the existing School then student-account barrier. A repeat of the original operation returns its original immutable action even if later transitions exist; it never changes the current head. The latest-event anti-existence query excludes removed heads before count and pagination, and current student authority is joined before pagination. No fixed candidate quota silently truncates years of references.

Five Restrict foreign keys pair the prior event/student/question and actual recipient/task revision/paper/release. A unique sequence and check constraint preserve transition structure. School scope is additionally checked against the recorded revision in the domain and application. Migration adds one table and no backfill; downgrade refuses to discard nonempty operation history. Native views request 20 records; server limits reuse existing assessment pagination limits.

Native and Web use the same four operations. Native has a current-school hub, an exact-question state panel and an original-result link. Web has a school hub and one explicitly selected question controller in the result view, avoiding automatic per-question RPCs for the whole paper. Neither client caches source content in collection storage. Pending commands contain only identifiers, expected baseline/release and the boolean action. They survive process loss for exact receipt lookup and explicit same-request retry; an unknown result cannot be replaced by a fresh operation. Hubs expose pending commands even when their collection is absent or its source gate closes. Closing local tracking is explicitly acknowledged and never rolls back a server fact. After recovering an older receipt both clients reread current state.

The student result contract adds a full-review-only collection configuration flag. GetMyResultForSchool checks selected school before returning a body or recording answer exposure; the original GetMyResult route remains compatible. Native links pin the selected frozen question, refusing a missing full-review target instead of silently showing another question. Hidden/score-only results still show only their allowed projection. New collection services join the private/no-store response filter; their request and persisted facts are metadata rather than private text.

Native workspace refresh now remembers an explicitly chosen valid role only in current-generation memory while hiding old workspace data during refresh. This fixes dual-role navigation losing its selected role when the verified projection is temporarily null. A new account generation resets the choice; no client selection grants identity or permissions.

Real WeChat/SDK/WXML/device behavior, complete browser and weak-network journeys, school retention/exit policy, production concurrency/capacity and the remaining native practice workflow are separate acceptance work. This extension never converts a bookmark into a permanently authorized source copy or independently measured learning evidence.
